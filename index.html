Basic Usage

Type your message and press Enter to send. Use Shift+Enter for new lines.

Tags

  • Add tags to messages using hashtags: #important, #todo
  • Click on tags in messages to filter by that tag
  • Use the sidebar to view and filter by available tags

Search

  • Start with / to search messages: /meeting notes
  • Search looks for messages containing all words
  • Press Enter to save the search for quick access
  • Combine with tags and numbers: /meeting #work :1

Tag Filters

  • Start with # to create tag filters: #important #todo
  • Press Enter to save the tag combination for quick access
  • Access saved filters in the sidebar
  • Combine with search and numbers: #work /email :2

Message Selection

  • Use :n to select the nth message: :3
  • Can be combined with search and tags: #todo /urgent :1
  • Operations are applied in order: #work /email :3 filters by work tag, then searches for email, then selects the 3rd result
